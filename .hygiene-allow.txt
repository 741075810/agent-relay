# Hygiene allowlist: `rule  path  reason`
#
# A reason is mandatory and is checked by test_publish_hygiene.py -- an exception
# without a reason becomes indistinguishable from an oversight within one release.
# Entries match by rule and path prefix, so an entry excuses every finding of that rule
# in that file. That is coarse on purpose (excerpts are masked and would be fragile to
# match on), and it is why the scan prints every excused line on every run: the point of
# the allowlist is to keep the judgement visible, not to make the output quiet.
#
# Nothing here may be added to silence a finding without knowing what the value is.

# build_launcher.ps1 passes it at build time. Replacing it means rebuilding

# both out of scope for a change that must not require the operator to do anything.
